設定（只需一次）
-------------------------------------------------------------------------------
1. 將以下內容加入 ~/.bashrc 或 ~/.zshrc：

   alias gops='python3 /home/janes/Projects/AI/git-ops/scripts/git_ops.py --from-text'

2. 重新載入 shell：

   source ~/.bashrc


基本使用
-------------------------------------------------------------------------------
gops "你的自然語言指令" | bash

範例：
  gops "stash my changes" | bash
  gops "commit 'fix bug' and push" | bash
  gops "checkout main" | bash


常用指令速查表
-------------------------------------------------------------------------------

Stash 暫存操作：
  gops "stash"                         儲存當前更改
  gops "stash list"                    列出所有暫存
  gops "stash pop"                     套用並移除最新暫存
  gops "apply stash 0"                 套用特定暫存

搜尋與資訊：
  gops "search for 'TODO' in *.py"     搜尋程式碼
  gops "grep 'pattern' ignore case"    不分大小寫搜尋
  gops "show reflog"                   查看操作歷史
  gops "blame file.py"                 查看誰改了什麼

重置與撤銷：
  gops "undo last commit"              軟重置 HEAD~1
  gops "unstage all"                   取消暫存所有檔案
  gops "hard reset to origin/main"     硬重置（警告！）

分支管理：
  gops "checkout main"                 切換到 main
  gops "create branch feature/new"     建立新分支
  gops "delete branch old locally"     刪除本地分支

Commit 與 Push：
  gops "commit 'message' and push"     提交並推送
  gops "amend last commit"             修改最後一次 commit

進階操作：
  gops "cherry-pick abc123"            套用特定 commit
  gops "merge develop"                 合併分支
  gops "squash last 3 commits"         互動式 rebase
  gops "create tag v1.0 and push"      建立並推送標籤
  gops "clean untracked"               預覽檔案清理

-------------------------------------------------------------------------------
✓ 執行前預覽：gops "command"（不要加 | bash）
✓ 破壞性操作需要輸入 "YES" 確認
✓ 使用 --force-with-lease 而非 --force

環境變數
-------------------------------------------------------------------------------
REMOTE=upstream gops "push" | bash           使用不同的 remote
CONFIRM_DESTRUCTIVE=0 gops "reset" | bash    跳過確認（危險！）


故障排除
-------------------------------------------------------------------------------
問題：找不到命令
解決：使用完整路徑：python3 /path/to/git-ops/scripts/git_ops.py ...

問題：權限不足
解決：chmod +r scripts/git_ops.py

問題：不在 git 儲存庫中
解決：先 cd 到你的 git 儲存庫


進階用法
-------------------------------------------------------------------------------

預覽模式（不執行）：
  gops "complex operation"              # 只顯示，不執行

儲存為腳本：
  gops "operation" > script.sh          # 儲存
  cat script.sh                         # 檢查
  bash script.sh                        # 執行

建立快捷函數（加入 ~/.bashrc）：
  gopsrun() {
      python3 /path/to/git-ops/scripts/git_ops.py --from-text "$*" | bash
  }

  使用：gopsrun "commit 'fix' and push"


實用別名範例
-------------------------------------------------------------------------------
加入 ~/.bashrc 或 ~/.zshrc：

  alias gs='gops "stash" | bash'
  alias gsu='gops "stash pop" | bash'
  alias gm='gops "checkout main" | bash'
  alias gpu='gops "pull" | bash'
  alias gc='function _gc() { gops "commit \"$1\" and push" | bash; }; _gc'

使用：
  gs                                    # 暫存
  gsu                                   # 彈出暫存
  gm                                    # 切換到 main
  gc "修復 bug"                          # commit 並 push

常見問題 FAQ
-------------------------------------------------------------------------------

Q: Windows 上可以用嗎？
A: 可以！在 PowerShell 中執行即可。

Q: 會不會覆蓋我的 git 設定？
A: 不會。git-ops 只生成標準 git 命令，完全遵守你的設定。

Q: 安全嗎？
A: 是的！有完整的安全檢查和確認提示。

Q: 需要網路嗎？
A: 不需要！完全離線運行，零 AI 依賴。

Q: 需要付費嗎？
A: 完全免費！無限次使用，零 token 成本。
