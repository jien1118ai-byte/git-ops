  三種安裝方式 / Three Installation Methods
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

┌────────────────────────────────────────────────────────────────────────┐
│ 方式 1：一鍵全域安裝（最推薦） ⭐                                      │
└────────────────────────────────────────────────────────────────────────┘

  適合：個人日常使用，所有專案都能用

  指令：
    ./install.sh

  步驟：
    1. 執行安裝腳本
    2. 選擇 "1) 全域安裝"
    3. 重新載入 shell: source ~/.bashrc
    4. 測試: gops "status" | bash

  安裝位置：~/tools/git-ops/
  配置位置：~/.git-ops.yml

  優點：
    ✓ 任何目錄都能使用
    ✓ 自動設定 alias
    ✓ 一次安裝終身使用

───────────────────────────────────────────────────────────────────────────

┌────────────────────────────────────────────────────────────────────────┐
│ 方式 2：專案內安裝（團隊協作） 👥                                      │
└────────────────────────────────────────────────────────────────────────┘

  適合：團隊專案，版本統一

  指令：
    ./install-to-project.sh /path/to/your/project

  步驟：
    1. 執行專案安裝腳本
    2. 指定專案目錄
    3. 使用 ./gops.sh "命令" | bash

  安裝位置：<專案>/tools/git-ops/
  配置位置：<專案>/git-ops.yml（團隊共用）

  優點：
    ✓ 團隊成員使用相同版本
    ✓ 配置可提交到版本控制
    ✓ 離線可用

───────────────────────────────────────────────────────────────────────────

┌────────────────────────────────────────────────────────────────────────┐
│ 方式 3：手動安裝（最靈活） 🔧                                           │
└────────────────────────────────────────────────────────────────────────┘

  適合：自訂安裝位置

  步驟：
    1. 複製檔案到目標位置
       cp -r scripts /your/custom/path/
       cp requirements.txt /your/custom/path/

    2. 安裝依賴
       pip install -r /your/custom/path/requirements.txt

    3. 設定 alias
       alias gops='python3 /your/custom/path/scripts/git_ops.py --from-text'

    4. 添加到 shell 配置
       echo "alias gops='...'" >> ~/.bashrc

  優點：
    ✓ 完全自訂
    ✓ 適合特殊環境
    ✓ 靈活性最高

┌────────────────────────────────────────────────────────────────────────┐
│ 手動安裝                                                                │
└────────────────────────────────────────────────────────────────────────┘

  最小安裝（僅核心）：
    cp scripts/git_ops.py ~/bin/
    alias gops='python3 ~/bin/git_ops.py --from-text'

  完整安裝：
    mkdir -p ~/tools/git-ops
    cp -r scripts ~/tools/git-ops/
    cp requirements.txt ~/tools/git-ops/
    pip install -r ~/tools/git-ops/requirements.txt
    alias gops='python3 ~/tools/git-ops/scripts/git_ops.py --from-text'

  必要檔案清單 / Required Files
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  最小安裝（基本功能）：
    scripts/git_ops.py          # 核心腳本（必須）

  推薦安裝（完整功能）：
    scripts/
    ├── git_ops.py              # 核心腳本
    ├── config_manager.py       # 配置系統
    ├── usage_logger.py         # 使用追蹤
    └── pattern_analyzer.py     # 模式分析
    requirements.txt            # 依賴清單（PyYAML）
    git-ops.example.yml         # 配置範本

  可選檔案（文檔）：
    SKILL.md                    # 功能說明
    CONFIG_GUIDE.md             # 配置指南
    QUICKSTART.txt              # 快速參考
    INSTALLATION_GUIDE.md       # 安裝指南

  依賴需求 / Dependencies
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  必須：
    ✓ Python 3.6+
    ✓ Git

  可選（用於配置檔功能）：
    ✓ PyYAML >= 6.0

  安裝 PyYAML：
    pip install PyYAML
    # 或
    pip install -r requirements.txt

  檢查依賴：
    python3 --version         # 應該 >= 3.6
    git --version            # 任意版本
    python3 -c "import yaml" # 檢查 PyYAML（可選）

  安裝後驗證 / Post-Installation Verification
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. 測試基本功能
     gops "status" | bash

  2. 測試圖形化
     gops "log graph" | bash

  3. 測試中文支援
     gops "儲存變更" | bash

  4. 檢查配置（如果安裝了）
     ls ~/.git-ops.yml
     cat ~/.git-ops.yml

  5. 檢查使用記錄（如果啟用了）
     ls ~/.git-ops/usage.jsonl

  安裝腳本參數 / Installation Script Options
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  install.sh               # 交互式全域安裝
    - 自動偵測 shell
    - 自動設定 alias
    - 創建配置範本
    - 安裝依賴

  install-to-project.sh    # 專案內安裝
    - 複製到專案目錄
    - 創建包裝腳本

    - 更新 .gitignore

  uninstall.sh             # 卸載
    - 移除安裝目錄
    - 移除配置（可選）
    - 移除 shell alias
    - 自動備份

  配置檔位置優先順序 / Config File Precedence
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  git-ops 會依序搜尋（先找到先用）：

    1. ./git-ops.yml              # 當前目錄
    2. ./.git-ops.yml             # 當前目錄（隱藏）
    3. <git-root>/git-ops.yml     # Git 倉庫根目錄
    4. ~/.git-ops.yml             # 使用者家目錄 ⭐
    5. ~/.config/git-ops/config.yml

  建議：
    - 個人配置：~/.git-ops.yml
    - 團隊配置：<專案根>/git-ops.yml

  常見問題 / FAQ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Q: 我應該選擇哪種安裝方式？
  A: 個人使用 → 全域安裝
     團隊專案 → 全域安裝 + 專案配置檔

  Q: 需要 sudo 權限嗎？
  A: 不需要，所有安裝都在用戶目錄

  Q: 可以不裝 PyYAML 嗎？
  A: 可以，但無法使用配置檔功能

  Q: 如何升級？
  A: 重新執行 install.sh 即可

  Q: 如何在多台電腦同步配置？
  A: 將 ~/.git-ops.yml 加入 dotfiles 版本控制

  推薦安裝流程 / Recommended Installation Flow
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  第一次使用（個人）：

    1. ./install.sh                    # 一鍵安裝
    2. source ~/.bashrc                # 重載 shell
    3. gops "status" | bash            # 測試
    4. nano ~/.git-ops.yml             # 自訂配置（可選）
    5. cat QUICKSTART.txt              # 查看快速參考

  團隊專案：

    1. ./install.sh                    # 每個成員全域安裝
    2. cd /path/to/project
    3. ./install-to-project.sh .       # 專案內安裝
    4. 編輯 git-ops.yml                # 團隊配置
    5. git add tools/ git-ops.yml      # 提交到版本控制
    6. git commit -m "Add git-ops"
