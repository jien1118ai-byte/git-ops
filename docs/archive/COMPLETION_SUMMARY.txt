🚀 快速開始 / Quick Start:

  1. Install dependencies:
     pip install -r requirements.txt

  2. Initialize configuration:
     python3 scripts/git_ops.py --init-config

  3. Edit configuration:
     nano ~/.git-ops.yml

  4. Add your aliases:
     aliases:
       s: stash
       m: checkout main
       cp: commit and push

  5. Use shortened commands:
     gops "s" | bash        # Instead of "stash"
     gops "m" | bash        # Instead of "checkout main"
     gops "cp 'fix'" | bash # Instead of "commit 'fix' and push"
